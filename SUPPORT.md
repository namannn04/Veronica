# Support

## Questions and Usage Help

Start with [docs/RUNNING.md](docs/RUNNING.md), which covers running Veronica,
the notch, and troubleshooting. `vr diagnose` prints the version, the session,
and where Veronica keeps its state, which answers most setup questions.

If that does not help, open an
[issue](https://github.com/namannn04/Veronica/issues/new/choose). Include the
Veronica version, how you installed it (Debian package, apt repository,
AppImage, Flatpak, or Snap), your Ubuntu and GNOME Shell versions, and the
output of `vr diagnose` when it is relevant.

The project is maintained on a best-effort basis. Response times are not
guaranteed, but clear reproductions and focused questions are easier to answer.

## Bugs and Feature Requests

Use the repository's issue forms for reproducible bugs and focused feature
requests. Search existing issues first, and remove credentials, agent history,
and other private data from logs and screenshots.

## Security and Conduct

Report vulnerabilities through the process in [SECURITY.md](SECURITY.md), not
through an issue. Report community conduct concerns using the private contact
guidance in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
